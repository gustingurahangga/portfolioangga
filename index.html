About Me

Saya Gusti Ngurah Agung Angga Wibawa, mahasiswa lulusan Program Studi D3 Manajemen Informatika di Politeknik Negeri Bali. Dalam bidang akademik, saya memiliki pengalaman dalam berbagai proyek pengembangan website dan aplikasi menggunakan tools seperti Android Studio dan Visual Studio Code.

Saya merupakan lulusan Program Studi D3 Manajemen Informatika, Jurusan Teknologi Informasi, Politeknik Negeri Bali. Memiliki pengalaman dalam berbagai proyek pengembangan website dan aplikasi serta terbiasa menggunakan berbagai teknologi dan tools dalam pengembangan sistem.

Selain fokus pada aspek teknis, saya juga memiliki pengalaman berorganisasi dan dipercaya untuk mengemban amanah sebagai Ketua Bidang Pengabdian Masyarakat di Badan Eksekutif Mahasiswa tahun 2025. Pengalaman ini telah mengasah kemampuan saya dalam kepemimpinan, komunikasi publik, kerja sama tim, serta pemecahan masalah secara efektif.

School Profile Website –
SMA Negeri 1 Bangli

Merancang dan mengembangkan website profil sekolah sebagai proyek akhir mata kuliah Desain Web. Website menyediakan halaman beranda, profil sekolah, visi dan misi, program kerja (GANAS, Bulan Bahasa Bali, Hibernasi, dan Galaksi), galeri kegiatan, serta informasi sekolah dengan desain yang modern dan responsif.

Pengembangan dilakukan menggunakan HTML dan CSS dengan mengutamakan pengalaman pengguna (UI/UX), konsistensi desain, dan kemudahan navigasi.

Teknologi: HTML, CSS, Responsive Design
